# COMMITTERS

This document lists the core committers of the react-native-location HarmonyOS adaptation repository.

Committers are responsible for the day-to-day maintenance of the repository, including issue triage, code review, release management, and documentation updates.

## Becoming a Committer

1. Contribute continuously to this repository (bug fixes, feature adaptations, documentation improvements);
2. Be nominated by an existing committer and approved by the maintainer team;
3. Please update this file when your first contribution is merged.
